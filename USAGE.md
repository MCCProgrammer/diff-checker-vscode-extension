# Diff Checker: Usage Guide

The [README](README.md) shows everything with animations. This is the short version.

## 1. Open it

- Right-click in an editor → **Show Diff Checker**
- Or the Command Palette → **Diff Checker: Show Diff Checker**

There is no default keyboard shortcut. Add one in **Keyboard Shortcuts** by searching for "Diff Checker".

## 2. Add the two texts

- Paste or type into **Original text** and **Changed text**
- **↑ Active** loads the file you were last editing
- **📁 Browse...** loads a file from disk
- Right-click a selection → **Load Selection to Text A** / **Load Selection to Text B**
- **Reset** clears a box

## 3. Compare

Click **See differences**:

- changed lines face each other, with only the changed words highlighted
- added lines appear on the right, removed lines on the left
- the summary counts the differences and the changed, added and removed lines

## 4. Ignore what doesn't matter

Tick **Ignore whitespace**, **Ignore case** or **Ignore blank lines**. The result updates straight away and your choices are remembered.

## 5. Open in VS Code's diff editor

**Open in VS Code's diff editor** opens the same comparison in the built-in diff editor.
